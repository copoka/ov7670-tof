# Измерение времени строки `T_row` по полосе света

## Что нужно (стенд)

* OV7670 в YUV-режиме, **AGC/AEC OFF**, **короткая экспозиция** (рег. `AECH` /
  `AECL`; иначе вспышка «тонет»).
* Строб: **внешняя неадресная LED-лента через MOSFET**, затвор — GPIO ПЛИС.
  Не WS2812 (медленный) и не встроенный LED3 (слабый).
* UART TX на PIN_42 (`/dev/ttyACM1`, 115200 8N1) для дампа профиля.

## Процедура

1. **Тайминг кадра.** Снять дамп, взять заголовок
   `F<frame> <lines> <px> <cycles>`. `T_frame = cycles/50e6`,
   `T_row = cycles/lines`. (Для QQVGA ожидается: ~64 мс, 120 строк,
   `T_row ≈ 533 мкс`.)
2. **Строб.** Импульс ~`T_row` (≈26 667 системных тактов при 50 МГц),
   синхронный началу кадра; задержку **свипуть** по кадру.
3. **Захват.** Для каждой задержки — дамп профиля (`R<row> <mean>`).
   Полоса = строка(и) с яркостью выше фона.
4. **`T_row`.** `T_row = Δdelay / Δrow` при смещении полосы на `Δrow` строк.
   Сверить с `cycles/lines`.
5. **Контраст/ширина.** Оценить число строк с промежуточной яркостью
   (мягкость кромки) и разницу «полоса−фон».

## Разбор дампа (Python, без зависимостей)

```python
import re
d = open('dump.txt').read().splitlines()
rows = [(int(m.group(1),16), int(m.group(2),16))
        for l in d for m in [re.match(r'R([0-9A-Fa-f]{4}) ([0-9A-Fa-f]{2})', l)] if m]
# максимум = положение полосы
if rows:
    r, v = max(rows, key=lambda t: t[1])
    print('band row', r, 'val', v)
```

## Типичные проблемы

| Симптом | Причина | Что делать |
|---------|---------|-----------|
| Профиль плоский, полосы нет | экспозиция ≫ `T_row` | укоротить `AECH`/`AECL` (~1 строка) |
| Полосы нет даже при короткой экспозиции | слабый/далёкий свет | яркая LED-лента, ближе к сцене |
| Вспышка «размыта» на много строк | импульс ≥ `T_row` | импульс ~`T_row` |
| Строб не мигает | WS2812 / нет MOSFET / нет питания | неадресная лента + MOSFET + отдельное питание |

## Границы метода

Даже с идеальной полосой: **ToF (дальность) по OV7670 недостижим** —
`δd ≈ c·T_row/2 ≈ 9.8 км`, а фазовая модуляция при `T_exp ≥ T_row` невидима
(`sinc → 0`). Метод даёт **`T_row`**, а не расстояние. Глубина — только
структурированный свет / триангуляция.
