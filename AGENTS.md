# OV7670 ToF / Rolling-shutter — Agent Guide

## Что это за репозиторий

Исследовательский проект: **можно ли сделать ToF-камеру (или измеритель глубины)
из дешёвой камеры OV7670 + импульсного света**, и какие измерения при этом
физически возможны. Выделен из эксперимента `004_rolling_shutter` проекта
`Altera_FPGA_OMDAZZ` (там остались общие модули и история).

Ключевой результат предыдущего исследования (перенесён в `docs/theory.md`):
**прямой и фазовый (AMCW) ToF на OV7670 невозможен** — экспозиция сенсора не
короче времени строки, поэтому фаза/задержка модуляции не наблюдаются.
Реалистичные задачи — **измерение времени строки** по положению световой
полосы, **структурированный свет** (TFT-проектор) и **лазерная триангуляция**.

> Статус: **скелет проекта**. Реализация RTL/железа — задача агентов
> (см. `docs/PROMPT.md`).

## Аппаратное обеспечение

| Компонент | Значение |
|-----------|----------|
| FPGA | Altera Cyclone IV E **EP4CE6E22C8N** (EQFP-144, 6K LE, C8) |
| Плата | OMDAZZ (ревизия UNKNOWN) |
| Камера | OV7670 (DVP 8-бит + SCCB), QQVGA 160×120 |
| Дисплей | TFT 2.4″ 240×320, Intel-80 16-бит, ILI9341-совместимый (write-only) |
| Строб | **внешняя LED-лента (неадресная) через MOSFET**; управление — GPIO ПЛИС |
| Телеметрия | UART TX, 115200 8N1, CH342 → `/dev/ttyACM1` |
| Программатор | USB-Blaster (JTAG) |

> **Не выдумывай пины.** Источник истины — `board/` (выдержка пинмапа OMDAZZ)
> и MCP `pinmap`. Любой новый пин сначала сверяй, потом используй.

## Подтверждённые факты (перенесены из 004)

* **Камера (картинка на экран)** — полная таблица `ov7670_regs` (RGB565,
  AGC/AEC **ON**, гамма, AWB); luma ≈ `(R + 2G + B)/4`.
* **Камера (измерения)** — YUV-таблица (`ov7670_regs_yuv`, AGC/AEC **OFF**,
  фиксированная экспозиция), `Y` в младшем байте.
* **TFT** — 16 бит **RGB565**, `MADCTL=0x08` (BGR + портрет), явное окно
  `CASET/PASET`, `RAMWR` перед заливкой, 1 пиксель = 1 16-битная запись.
  Панель **write-only** (ID не читается).
* **Тайминг QQVGA** (измерено): кадр ≈ **3 198 719** системных тактов @50 МГц
  ≈ **64 мс** (≈15.6 fps), **120 строк**, **160 px**; `T_row ≈ 26 667` тактов
  ≈ **533 мкс**.
* **Строб встроенным LED3 не работает** — слишком слабый; нужен яркий внешний
  излучатель.

## Правила работы

1. **Сначала читай** `AGENTS.md`, `docs/*`, `board/`, MCP `pinmap`; потом ищи
   в интернете. Всё проверенное фиксируй в `docs/` (это основной артефакт).
2. **Не выдумывай** назначение пинов, регистров, таймингов. Числа берутся из
   datasheet, симуляции или **измерения на железе**.
3. **HDL читаемо**: осмысленные имена, явные тактовые домены и сброс, по одному
   `always_ff` на процесс, к каждому модулю — testbench.
4. **Итерация через измерение**: прошил → снял данные по UART → разобрал →
   вывод в `docs/`. Не «на глаз».
5. **Секреты**: токены/пароли/`.env`/ключи в репозиторий **не коммитить**
   (см. `.gitignore`). Конфиги MCP не должны содержать кредов.
