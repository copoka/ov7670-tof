# Pin sharing на плате OMDAZZ Cyclone IV (EP4CE6E22C8N)

Камера OV7670 подключается к **общим выводам периферии** (GPIO-гребёнка,
распиновка MUDAL P14): штатных «камерных» пинов на плате нет. Любой
эксперимент с камерой занимает пины, которые в других экспериментах нужны
LED/кнопкам/VGA/I²C/IR. Таблица — чтобы не назначать один пин двум устройствам.

Сверено: `pinmap.md` (uCore .qsf + схема V2.1) и рабочие сборки 001
(`build_cam*/top_cam*.qsf`, bring-up 2026-09-08/09).

| Пин | Штатная функция платы | Камера (MUDAL P14, как в 001/002) | Занят камерой |
|-----|----------------------|-----------------------------------|---------------|
| 23  | кварц 50 МГц         | — | нет |
| 25  | кнопка RESET (rst_n) | — | нет |
| 84  | LED1                 | SCCB SCL (`cam_scl`, top_cam2/002) | да* |
| 85  | LED2                 | SCCB SDA (`cam_sda`) | да* |
| 86  | LED3                 | — (свободен; индикатор в top_cam2) | нет |
| 87  | LED4                 | XCLK | да |
| 88  | KEY1                 | VSYNC | да |
| 89  | KEY2                 | HREF | да |
| 90  | KEY3                 | PCLK | да |
| 91  | KEY4 / button_in     | — | нет |
| 98  | I2C_SDA (AT24C08)    | cam_d[7] | да |
| 99  | I2C_SCL (AT24C08)    | cam_d[6] | да |
| 100 | IR-приёмник          | cam_d[5] | да |
| 101 | VGA_HSYNC (nCEO!)    | cam_d[4] — требует `USE AS REGULAR IO` | да |
| 103 | VGA_VSYNC            | cam_d[3] | да |
| 104 | VGA_B                | cam_d[2] | да |
| 105 | VGA_G                | cam_d[1] | да |
| 106 | VGA_R                | cam_d[0] | да |
| 110 | зуммер beep          | — (использует 002) | нет |

\* SCCB занимает LED1/LED2 только при включённой инициализации (`CAM_NO_SCCB=0`).
В варианте top_cam (дефолтный YUV, без SCCB) пины 84/85 свободны.

## Следствия для новых экспериментов

* Камера + VGA **одновременно невозможны** (пересечение d[3:0] с
  VGA синхро/цветами; плюс pin 101 = nCEO).
* Камера + I²C EEPROM (98/99), IR (100), KEY1..3 (88..90), LED1/2/4 — тоже
  взаимоисключающие, если камера подключена физически.
* Свободные почти всегда: 86 (LED3), 91 (KEY4), 110 (beep), UART 114/115,
  SDRAM, 7-seg (DIG/SEG), LCD — при отсутствии камеры на шлейфе.
* 002_brightness_buzzer использует кадр «камера + beep»: LED-индикации не
  остаётся (84/85=SCCB, 87=XCLK) — яркость озвучивается тоном.

## Раскладка камеры + измерительного стенда (004_rolling_shutter)

Эксперимент `004` добавляет к раскладке камеры (001/002) три линии:
строб света, UART-телеметрию и кнопку дампа.

| Пин | Штатная функция платы | В 004 | Занят |
|-----|----------------------|-------|-------|
| 87  | LED4 | XCLK камеры (toggle-FF от sys) | да |
| 88  | KEY1 | VSYNC | да |
| 89  | KEY2 | HREF | да |
| 90  | KEY3 | PCLK | да |
| 98..106 | I²C/IR/VGA | cam_d[7:0] | да |
| 84  | LED1 | SCCB SCL | да |
| 85  | LED2 | SCCB SDA | да |
| 114 | UART TX | телеметрия (TX) — **в текущем стенде занят экраном**, UART перенесён на PIN_42 | да |
| 42 | SDRAM LDQM (свободен) | UART TX в 004 (вместо 114) | да |
| 144 | LCD D2 | **подсветка монитора** (TFT 003); строб света в 004 должен быть на другом пине | да |
| 91  | KEY4 | запрос дампа профиля (активен низом) | да |
| 86  | LED3 | heartbeat 1 Гц | да |

Вывод: **одна камера + стенд измерения помещаются** (7-seg, LCD-шина,
SDRAM, beep, PS2 остаются свободны). Вторая камера по-прежнему не
помещается: ей нужен второй свободный набор из 8+4 пинов, а свободны
только 7-seg (12), LCD (11) и часть SDRAM.

> **Факт (проверено в 004):** XCLK камеры формируется toggle-FF, поэтому
> `XCLK_DIV=2` даёт **sys/4 = 12.5 МГц**, а не 25 МГц (как написано в
> `experiments/001_ov7670_avg_brightness/docs/clocking.md`).

Обновлять при каждом подтверждённом изменении распиновки/периферии;
открытые вопросы по уровням — `board/omdazz_cyclone_iv/README.md`.
