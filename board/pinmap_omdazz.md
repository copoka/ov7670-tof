# Проверенный пинмап платы OMDAZZ Cyclone IV

Сверено по официальной «Development board pin allocation table» из
репозитория `microCore-VHDL/uCore-for-Cyclone-IV`
(`documents/board/Development board pin information.pdf`) и схеме
`Development board schematic diagram V2.1.pdf` (копия:
`board/omdazz_cyclone_iv/reference/ucore_for_cyclone_iv/documents/board/`).
Назначение сигналов в `Quartus/fpga.qsf` совпадает.

> Плата выпускается также под именем **RZ-EASY**. Часть пинов совпадает
> у обеих маркировок; сверять при заказе/измерении.

## PS2 и IR

| Функция | Pin |
|---------|-----|
| PS_CLOCK | 119 |
| PS_DATA | 120 |
| IR | 100 |

> В uCore PS2/IR **не используются** — в `fpga.pin` эти пины значатся
> `RESERVED_INPUT_WITH_WEAK_PULLUP`. На плате разъём PS2 (6 pin) и ИК-приёмник
> присутствуют (схема: U10, R21/R22).

## VGA

| Сигнал | Pin |
|--------|-----|
| VGA_HSYNC | 101 |
| VGA_VSYNC | 103 |
| VGA_B | 104 |
| VGA_G | 105 |
| VGA_R | 106 |

> **Конфликт/ограничение:** pin 101 — специальный (nCEO/altera_reserved).
> В uCore `# pin 101 can not be used!` — VGA_HSYNC закомментирован в `.qsf`.
> На плате он выведен на разъём VGA, но использовать как обычный выход может
> быть невозможно/сложно (проверить конфигурацию nCEO).

## Питание и конфигурация

| Пункт | Значение |
|-------|----------|
| Вход питания | USB **или** 5V/2.1мм адаптер; переключатель питания |
| Стабилизаторы | 5V → 3.3V, 2.5V, 1.2V |
| VCCIO (все банки) | 3.3V (Quartus .pin: Bank1..8 3.3V) |
| Конфигурация | EPCS (AS), разъёмы AS и JTAG; MSEL0/1/2 → 2.5V (pull-up 10K) |
| CONF_DONE | 92, через 10K к 3.3V |
| nCONFIG | 14, через 10K |
| nSTATUS | 9, через 10K |
| DCLK/DATA0 | 12/13 (к EPCS), nCSO на pin 6 (к EPCS) |

> AS-конфигурация: EPCS4/EPCS16 (на схеме «EPCS4N EPCS16»). Программирование
> через JTAG (altera_reserved_tdi/tck/tms/tdo = 15/16/18/20) или AS.
