# board/ — reference (OMDAZZ Cyclone IV)

Копия проверенного пинмапа платы OMDAZZ из репозитория `Altera_FPGA_OMDAZZ`
(`board/omdazz_cyclone_iv/pinout/`):

* `pinmap_omdazz.md` — штатные функции выводов (LCD/7-seg/SDRAM/VGA/…).
* `pin_sharing_omdazz.md` — как пины делятся камерой/дисплеем/периферией.

Это **справочник**, а не истина в последней инстанции: перед использованием
пина сверяйся с MCP `pinmap` и реальной схемой.
