# Аппаратное обеспечение и конфигурация

## Плата / ПЛИС

* **Altera Cyclone IV E EP4CE6E22C8N**, EQFP-144, 6K LE, 30× M9K (276 480 бит).
* OMDAZZ (ревизия UNKNOWN). Такт платы 50 МГц (PIN_23), сброс — кнопка (PIN_25).
* Программатор USB-Blaster (JTAG): `quartus_pgm -c USB-Blaster -m JTAG -o "p;<file>.sof"`.

**Режимы (SCCB):**

* Для **картинки на экран**: полная таблица `ov7670_regs` (RGB565, **AGC/AEC ON**,
  гамма, AWB), QQVGA 160×120. Luma ≈ `(R + 2G + B)/4`.
* Для **измерений**: `ov7670_regs_yuv` (YUV, **AGC/AEC OFF**, фиксированная
  экспозиция); `Y` — в младшем байте кадра.
* Экспозиция: `AECH` (0x10, старший байт), `AECL`/`COM1` (0x04, младший),
  `GAIN` (0x00). Короткая экспозиция (~1 строка) нужна, чтобы строб дал
  узкую полосу. Учти: при `AECH=0x01, AECL=0x00` кадр был стабильно яркий,
  но полосы от строба не было (экспозиция ≫ `T_row`).

**Конфигурация панели (подтверждена):**

* Интерфейс Intel-80, **16 бит**, только запись (write-only; ID не читается).
* Команды — на `DB[7:0]` (младший байт).
* `COLMOD` (0x3A) = **0x55** (16 bpp, RGB565).
* `MADCTL` (0x36) = **0x08** (BGR + портрет). Панель нативно BGR: без бита
  `0x08` красный/синий меняются местами.
* Окно — `CASET` (0x2A) 0x0000..0x00EF (0..239), `PASET` (0x2B) 0x0000..0x013F
  (0..319); задавать **явно**.
* `RAMWR` (0x2C) — перед заливкой (без него данные не идут в GRAM).
* 1 пиксель = 1 16-битная запись (не 2 байта!).
* Питание: VCC → 5 В платы, GND → GND. Подсветка (LEDA) — от VCC, ПЛИС не
  управляет (по умолчанию горит).

## Строб (внешняя LED-лента)

* Тип: **неадресная** LED-лента (белая или аналоговая RGB 12 В/5 В).
  **WS2812/WS2812B — не годится** (медленный протокол + ШИМ ~1 кГц).
* Ключ: **MOSFET/транзистор** (например IRLZ44N / AO3400), затвор → GPIO ПЛИС,
  сток/исток — в разрыв питания ленты (low-side). GPIO ток ленты не тянет.
* Питание ленты — **отдельное** (5/12 В), общий GND с платой.
* Свободные пины-кандидаты под затвор (сверить с `board/`): **43, 55, 58, 60**
  (линии SDRAM — свободны, если SDRAM не используется), **110** (зуммер, если
  не нужен). Выбор — ADR в `docs/decisions/`.
* Для узкой полосы: короткий импульс ~`T_row` (~0.5 мс), свип задержки от
  начала кадра.

## UART

* TX FPGA — **PIN_42** (SDRAM LDQM, свободен), 115200 8N1.
* CH342 (WCH, «USB Dual Serial») → `/dev/ttyACM1` (канал 0).
* Формат дампа профиля: `F<frame:4hex> <lines:4hex> <px:4hex> <cycles:8hex>`,
  затем `R<row:4hex> <mean:2hex>` на каждую строку.

## Питание / безопасность

* VCCIO всех банков — 3.3 В. TFT/камеру не питать 5 В на входы (несовместимость).
* PIN_101 = nCEO: `USE AS REGULAR IO` (как в проверенных сборках).
* PIN_144 занят как `tft_db[4]` — **не** использовать под подсветку/строб.
