# ADR-0001 — Границы проекта: ToF vs измерения и альтернативы

Статус: accepted
Дата: 2026-10-23

## Контекст

Предыдущее исследование (`Altera_FPGA_OMDAZZ/004_rolling_shutter`) расчётно и
частично экспериментально показало: прямой (position) и фазовый (AMCW) ToF на
OV7670 **недостижимы**, потому что экспозиция сенсора не короче времени строки.

## Решение

Проект преследует две цели:

1. **Измерения, которые физически возможны**: тайминг камеры, `T_row` по
   положению полосы, контраст, построчное поведение сенсора.
2. **Практическая глубина**: оценить и (при желании) реализовать
   **структурированный свет** (TFT как проектор) и **лазерную триангуляцию**.

Прямой ToF **не реализуется** как заведомо недостижимый на этом сенсоре.

## Последствия

* Инструмент — строб + профиль строк по UART, а не «ToF-камера».
* Результат — числа и границы метода, а не карта глубины по ToF.
* Глубина — только через структурированный свет/триангуляцию (отдельные задачи).
