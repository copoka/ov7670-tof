# Измеренные факты (перенесено из 004, 2026-10-22)

Все числа получены на железе OMDAZZ (EP4CE6E22C8N), UART 115200 8N1.

## Тайминг камеры (QQVGA 160×120)

| Величина | Значение | Как получено |
|----------|----------|--------------|
| Кадр, системных тактов | **3 198 719** (`0x30CEFF`) | заголовок `F`, поле `cycles` |
| `T_frame` | **63.97 мс** (@50 МГц) | `cycles / 50e6` |
| `f_frame` | **15.6 fps** | `1/T_frame` |
| Строк | **120** (`0x78`) | заголовок `F`, поле `lines` |
| Пикселей в строке | **160** (`0xA0`) | заголовок `F`, поле `px` |
| `T_row` | **≈ 26 667** тактов ≈ **533 мкс** | `cycles / lines` |

> Это **измерено**, а не из комментария. `T_row` — стартовая точка для свипа
> строба: чтобы полоса сместилась на 1 строку, задержку меняют на ~26 667
> системных тактов.

## Камера

| Режим | Таблица | Результат |
|-------|---------|-----------|
| RGB565 (картинка) | `ov7670_regs` (AGC/AEC **ON**) | яркий кадр, mean ≈139, min 58, max 166 — **QR с листа виден на TFT** |
| YUV (измерения) | `ov7670_regs_yuv` (AGC/AEC **OFF**) | тёмный кадр, mean ≈40, max ≈73 |
| YUV + короткая экспозиция | `AECH=0x00`, `AECL=0x04` | яркость та же (~127): усиление `GAIN=0xFF` компенсирует |

* Дамп кадра по UART: 19200/19200 байт — кадр снимается полностью.
* Кадр QQVGA: 160×120, Y 8 бит (для картинки — luma из RGB565).

## Дисплей TFT

| Что | Значение |
|-----|----------|
| Цвета | верные (после `MADCTL=0x08` BGR) |
| Ориентация | портрет 240×320, верная |
| Чтение | **не работает**: `RDDID`/`RDID1..3` = `0x00` (панель write-only) |
| Память под кадр | RGB332 120×120 = 115200 бит (42%); RGB565 120×120 = 230400 бит — **не влезает** (нужно >30 M9K в двухклоковом режиме) |

## Строб (важно)

* Строб на встроенный **LED3 (PIN_86)** полосы **не даёт** — профиль строк
  плоский (~127 по всем 120 строкам). LED3 слишком слаб / не подсвечивает сцену.
* Причина также в длинной экспозиции: короткая вспышка «тонет» в ней.
* **Вывод:** для полосы нужен яркий **внешний** излучатель (LED-лента через
  MOSFET) и **короткая** экспозиция (~1 строка).

## Что это значит для ToF

* Наблюдаемое подтверждает `docs/theory.md`: при `T_exp ≥ T_row` модуляция
  света не даёт измеримой фазы/полосы → **ToF на OV7670 недостижим**.
* Реалистично измерить: `T_row` (положение полосы), тайминг, контраст.
* Глубину даёт только **структурированный свет** или **триангуляция**.
